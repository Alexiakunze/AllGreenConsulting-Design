# Official brand files

Copy the PNGs from the Google Drive folder **Identidade Visual › PNG** here
(keeping the original names). The app detects them automatically:

| File | Use in the app |
| --- | --- |
| `[agc] logo-horizontal-verde@2x.png` | Main logo (light backgrounds) |
| `[agc] logo-horizontal-colorida-branca@2x.png` | Negative logo (green backgrounds) |
| `[agc] logo-resumida-verde@2x.png` | Short logo (light backgrounds) |
| `[agc] logo-resumida-branca@2x.png` | Short logo (dark backgrounds) |
| `[agc] simbolo-branco-1@2x.png` | Symbol (dark backgrounds) |

While the files are missing, the app uses a provisional signature built from
the design tokens. You can also upload the files in the app under
**Identidade › Logos oficiais** (they are saved in the browser).
